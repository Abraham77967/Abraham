Smart Door System

Girls Who Code InfyMaker Award
In Progress

A smart door system developed for the Girls Who Code InfyMaker Award summer camp. The project uses an ultrasonic sensor to detect when objects approach within a specific distance, automatically opening the door. This innovative solution combines hardware prototyping, sensor integration, and mechanical design for enhanced accessibility.

75% Complete
Arduino Ultrasonic Sensors 3D Modeling Mechanical Design
